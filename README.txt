для работы нужен python 3.10+
mongo db
репозиторий:
git clone https://github.com/SamsonovD2/Dev_yatkin.git
cd Dev_yatkin

библиотеки нужные, установка через cmd 
pip install customtkinter requests beautifulsoup4 pymongo

запуск через cmd
python main.py или через ярлык в папке main.py

как пользоваться

1. Убедись, что в левом нижнем углу горит зеленый статус MongoDB: Активна.
2. На вкладке Сбор данных вставь ссылку (по умолчанию стоит https://books.toscrape.com), укажи количество страниц и нажми «Запустить парсинг».
3. Перейди на вкладку База данных (Поиск), введи слово для поиска (или оставь поле пустым, чтобы вывести всё) и нажми «Найти».
4. Для выхода нажми Завершить работу.

 main.py — графический интерфейс и связка всех модулей.
 parser_module.py — сам парсер сайтов.
 db.py — работа с MongoDB (сохранение, поиск, экспорт).
 start.vbs — тихий запуск приложения для Windows.
